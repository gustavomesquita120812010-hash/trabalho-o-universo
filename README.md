# Trabalho: O Universo

Este foi meu segundo projeto de desenvolvimento web, no qual pude colocar em prática e ampliar meus conhecimentos em HTML e CSS.

Durante o desenvolvimento, aprendi a trabalhar com imagens de fundo (*backgrounds*), criar links para navegar entre diferentes páginas e construir um cabeçalho (*header*), um elemento bastante utilizado em sites modernos.

Também pratiquei a utilização de imagens para inserir logotipos e outros elementos visuais, além de desenvolver minha capacidade de identificar e corrigir problemas no código.

Este projeto foi importante para minha evolução como desenvolvedor iniciante, pois me ajudou a compreender melhor a estrutura das páginas web e a importância da organização e dos elementos visuais na criação de um site.

**Tecnologias utilizadas:**
- HTML
- CSS

**Principais aprendizados:**
- Aplicação de imagens de fundo.
- Navegação entre páginas por meio de links.
- Criação e organização de cabeçalhos.
- Utilização de imagens e logotipos.
- Identificação e correção de erros no código.
